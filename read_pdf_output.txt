  How to use this document
  The tables below list every time limit and point value the scoring engine currently uses. All of them are
  placeholders based on “Ablauf_Notfall auf Normalstation_NBA.docx” and need medical review.
  • Leave New value empty if the current value is fine.
  • Enter a different number in New value to change it.
  • Use Comments for reasoning, conditions, or if a rule should be removed or worded differently.
  • Rows can be added at the end of any table for rules that are missing.
  Shaded columns are for your input. Each session starts at 100 points and the deductions below are
  subtracted from that.
